# Bauloo Styler Remake

An independent Fabric client mod project targeting Minecraft Java 1.21.0.

## Current foundation
- Press **G** to open the style control screen.
- Separate switches for Crystal, Anchor, Armor, Tools, Fire, Sky, Extras, and Cosmetics.
- Switch states are saved to `config/bauloo-styler-remake.json`.
- Settings screen does not pause single-player.

## Build
Requires Java 21 and Gradle 8.10.2 or compatible.

```sh
gradle build
```

The current commit is the configuration/menu foundation. Visual style effects are not yet included.
